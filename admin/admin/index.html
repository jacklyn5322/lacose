01 / MEMORY COVER
🖼️

上傳最後的手繪地圖

旅程結束後，從手機或電腦選擇最後完成的手繪地圖。確認預覽後發布，讓它顯示在回憶相簿最上方。

02 / RESET TEST DATA
↺

清除目前的測試紀錄

重新測試前，清除測試建立的景點、照片、闖關任務、回答及心得。已發布的手繪地圖不會被清除。

⚠️ 清除功能只應作用於「測試資料」。目前舊版資料尚未完整區分正式與測試紀錄，因此在雲端完成資料隔離前，這個按鈕不會執行刪除。
狀態：等待後端設定測試資料清除 API
連線狀態：尚未連接正式管理 API
目前這份是管理後台介面預覽。圖片選擇與預覽可直接測試；正式發布及安全清除，需先接上 Cloud Run 管理 API，並由伺服器驗證管理者權限。這樣才能確保資料真的同步到正式網站，也不會誤刪正式紀錄。

確定清除測試紀錄？

這個動作會刪除測試景點、照片、任務、回答與心得，無法復原。手繪地圖及正式資料應完整保留。
