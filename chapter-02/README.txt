重要限制（請務必閱讀）：
- 這仍是 GitHub Pages 前端原型，資料使用同一瀏覽器 localStorage；不是雲端資料庫，跨裝置/不同瀏覽器不會同步。
- admin/index.html 目前不是具備安全登入的正式管理後台。靜態網站無法安全地自行實作帳號驗證與權限控管；正式上線必須另接 Firebase/Supabase 等受保護的身分驗證、資料庫及檔案儲存，並以伺服器端規則限制管理者權限。不可把密碼或 API Key 寫入前端。
- AI 即時任務生成及網路搜尋仍未連接。game.html 的任務為示範流程，不能宣稱是 AI 結果。需有後端 API 與模型/搜尋服務金鑰才能正式完成。
- 照片與插畫以 Data URL 存入 localStorage，可能遇到容量限制；建議正式版改用雲端物件儲存。

部署時只替換第二章資料夾內容，不要覆蓋共同首頁、第一章或第五章。
