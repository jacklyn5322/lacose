第二章｜台南・即興冒險（前端流程原型）

正式網站入口：index.html
頁面：today.html（今日旅程）、game.html（現場任務）、gift.html（三份驚喜禮物）、album.html（回憶相簿）
管理介面原型：admin/index.html

部署：將 chapter-02 資料夾內容放入 GitHub Pages 的第二章目錄。不要覆蓋共同首頁、第一章或第五章。

重要功能狀態：
1. 首頁使用全螢幕背景構圖，三個正式入口。
2. 各頁提供回首頁及上一頁。
3. 景點、任務回答、照片及插畫目前存在同一瀏覽器 localStorage，僅供前端流程測試。照片可能受瀏覽器儲存容量限制。
4. 三份禮物名稱與意義需由管理者填入；目前沒有擅自編寫禮物內容。
5. 任務目前是示範任務，並非 AI 即時生成，也沒有網路搜尋。正式 AI 需要獨立後端代理服務及 API Key；絕不可將金鑰寫入前端或 GitHub。
6. admin/ 是管理介面原型，並非安全的獨立後台。GitHub Pages 靜態網站不能提供真正帳號驗證或跨網域資料庫。正式管理後台需部署到獨立網域/服務，使用登入驗證及資料庫權限。
7. 正式網站與管理後台若要共用資料，需設定受保護的雲端資料庫與檔案儲存；本原型目前不具跨裝置同步。

測試：首頁 → 今日旅程 → 輸入地點 → 完成任務/上傳照片 → 回憶相簿；另測試三份禮物逐一上傳。管理頁可填禮物意義、匯出 JSON、清除本機測試資料。
